01做法：两路检索，一条表格通道

巨潮资讯下载 12 份 2024 年报全文 → PyMuPDF 按页抽文字与有框线表格 → 表格还原成「表头 + 行列」→ 每块带公司、章节、页码，表格块带表题 → BM25 + 256 维 LSA 向量（字符 2–4 gram TF-IDF → SVD）→ RRF 融合（0.45 / 0.55）。

问题含多家公司时，先逐公司召回再合并。数值题走两阶段：混合检索找章节，再用「指标 + 表名」锚定查询回主表，例如「合并资产负债表 + 合同负债 + 期末余额」。答案只引用召回块，不调用大模型。

02结果：数字全对，证据路径不全都漂亮

  • 10/10 题数值正确：8 道单公司题、2 道跨公司全景题。
  • 7/8 单公司题的金标准页进入问题级 top-12；9/10 题的数值块进入问题级 top-12。
  • 跨公司营收前三、归母净利润增速最高/最低全部正确；逐公司召回后 12/12 家都有可比数值。

“答对”与“检索到”不是一回事：q07 的问题级 top-12 没有正确答案所在的 p.62，靠第二阶段才捞回来。

03答得好：主表 + 明确指标

稳营业总收入、归母净利润、经营现金流、研发投入：公司 + 指标 + 主要会计数据表，一次命中，页码可核（q01/q02/q04/q05/q08）。

稳同一张表里的双指标：古井贡酒营收与归母净利润（q06），行定位稳定。

稳跨公司排序/极值（q09/q10）：逐公司召回 + 统一口径排序，避免茅台、五粮液霸榜。

04翻车：同名表、合并/母公司、口径

  • q07 今世缘合同负债：问题级 top-12 全是附注里的「合同负债 / 期末余额」，没有 p.62 合并资产负债表；锚定查询才返回 15.93 亿元。答案对，路径脆。
  • q03 泸州老窖合同负债：先命中 p.25 管理层讨论表，而不是 p.87 合并资产负债表；数值一致，但口径解释依赖表头识别。
  • q02 五粮液经营现金流：曾被 p.8 分季度表的 Q1 值 5.16 亿元干扰；系统用「四列季度值 + 无年度表头」规则剔除了它。
  • q09 古井贡酒：营业总收入行未命中，回退营业收入口径，已在备注披露。

05为什么：表格结构决定上限

1. 多行表头 / 空列 / 单位 / 两套报表：年报表格常把表头拆成两三行，合并报表与母公司报表又长得几乎一样。数值题答错，多数不是没找到章节，而是列对齐或报表范围选错。

2. 向量擅长“哪一页”，不擅长“哪一行”：「合同负债」「期末余额」在几十张表里重复，BM25 与向量都缺少“这是合并主表”的区分度；必须加表名、科目、页码约束。

3. 全景题不是把 top-k 调大：全局 top-12 会被头部公司占满；逐公司召回 + 统一指标 + 排序，才是可比的全景答案。

06建库，还是微调？

问题选择理由
单/跨公司数值、同比、排名、占比建库答案在表里，可枚举、可核验；微调不增加事实可靠性
口径判断（总收入 vs 收入、合并 vs 母公司）建库 + 结构规则靠表名/报表范围元数据，不靠语言能力
“为什么合同负债下降”“预收款说明什么”微调 / LLM 推理需要行业语义、因果链与多步判断；检索只能给证据
跨年度战略变化、管理层语气微调 + 检索文本长、信号弱，纯检索召回不稳
一句话：事实题建库，判断题微调；先把口径和表格结构做对，再谈模型。

07边界

10 道题、12 家公司、单一年份；向量是离线 LSA，不是神经嵌入；表格抽取是启发式，未做 OCR；答案是抽取式，不含生成式归因。结论应视为这套语料与这套题目上的工程判断，不是行业定论。
